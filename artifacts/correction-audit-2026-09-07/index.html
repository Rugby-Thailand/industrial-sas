Storage planner: easier corrections

Actual browser recordings from the local QA warehouse. Desktop and Thai mobile checks. No audio; physical acknowledgements are simulated test actions.

1. Correct a stored location

Move beside the destination → search → edit coordinates → review/reserve → verify identities → confirm placement. Wrong destination codes stay blocked.

2. Correct only one unit

Open its pencil action → correct dimensions → review → save. The other units keep their codes, measurements and quantities.

3. Edit the location details directly

One click opens the exact location editor. Invalid dimensions block saving; cancellation leaves the location unchanged.
