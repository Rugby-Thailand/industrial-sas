# Packing design prompts

Generated using the built-in image_gen tool after implementing and testing packing. These are design choices, not screenshots of the implemented UI. The user will choose which visual treatment to implement. Icon-only actions must retain tooltips, accessible names and keyboard focus; essential field labels, units and errors remain visible.

## Option A — split panel

Use case: ui-mockup. Create a high-fidelity desktop web app design concept, option A, for a finished-goods packing and measurement workspace. Wide landscape 1600x1000 composition. Minimal professional industrial storage app, charcoal near-black background, subtly lighter panels, thin neutral borders, restrained blue accent, crisp readable typography. Very narrow left sidebar with icon-only navigation: cube selected, building, grid, settings. Compact warehouse dropdown and user avatar header, NO organization name. Main compact header FG-001 with pencil icon for edit and two-step breadcrumb product checkmark then packing. Two-column workspace: large realistic 3D wrapped cardboard pallet preview left with clear length 1.2m width 1.0m height 1.4m dimension arrows; slim icon-only camera toolbar for 2D/3D, rotate, zoom, fit, reset, expand. Right a tidy measurement inspector: packing type Pallet dropdown, quantity 500 pcs, labelled L W H with numeric fields 1.2 1.0 1.4 and m unit, optional weight field kg, checked measurement verification icon. Above workspace a compact total 1000 pcs and split settings quantity per pallet 500 and count 2, with distinct icon-only plus, divide/split, copy, undo controls. Bottom full-width allocation table two rows P-001 and P-002 each 500 pcs, dimensions 1.2 x 1.0 x 1.4, green checked icon, pencil and trash icon-only row actions. Selected row subtle blue accent. Footer allocated 1000/1000 and remaining 0 plus icon-only back, save disk, primary blue check-arrow to create and find storage. No text labels on action buttons. Keep essential field labels and values. Spacious, calm, functional, not decorative. Full page visible no cropped controls, no marketing, no huge headings, no large boxed search panel. One single finished screen, no collage, no annotations, no option title outside app.

## Option B — canvas first

Use case: ui-mockup. Generate one high fidelity desktop finished-goods packing app design, option B, canvas-first layout. Landscape 1600x1000. Minimal charcoal dark industrial app with muted blue accents and hairline borders, understated crisp typography, lots of breathing room. Tiny icon-only vertical navigation rail on far left. Compact horizontal topbar: warehouse dropdown Main Warehouse, FG-001 with pencil edit icon, completed product step then packing step, avatar. Main workspace is a large borderless interactive 3D canvas with a realistic shrink-wrapped carton pallet on wooden base, measurement arrows label 1.2 m length,1.0 m width,1.4 m height. Small floating top left icon-only view controls cube/flat view, rotation, zoom plus/minus, fit, expand. At right float a compact rounded inspector about 300px wide, labelled controls Pallet format dropdown, Qty 500 pcs, L 1.2 m W 1.0 m H 1.4 m, optional Weight kg and small verified dimensions checkbox. Canvas bottom a slim floating dock with add plus, divide/equal-split, copy and trash icons ONLY, no button text. Below canvas two elegant horizontal compact pallet cards side by side P-001 and P-002, each with tiny isometric pallet thumbnail,500 pcs,1.2 x 1.0 x 1.4 m, verified check and small edit/remove icons; P-001 selected. A compact allocation progress strip with 1000/1000 pcs and Remaining 0; small total quantity and per-pallet split numeric inputs remain present and usable. Bottom right a strong blue icon-only check+arrow action to create pallets and proceed to storage; bottom left back and disk/save icons. Show a small open equal split popover anchored to divide icon, with 1000 pcs / 2, preview 500 + 500, icon-only close and check controls, positioned in empty canvas area without covering pallet or inspector. All functionality visible: FG edit, total quantity, per-pallet and equal-count splits, add/select/edit/delete/copy pallet, measurements optionalweight, verification, totals, save/back/confirm. Essential labels on numeric fields but no text labels on action buttons. No large card chrome, no marketing text, no decorative dashboard charts, no organization name. Polished implementable app screen, one screen not collage.
