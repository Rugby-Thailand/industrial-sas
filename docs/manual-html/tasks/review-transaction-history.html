ตรวจสอบประวัติการเคลื่อนไหวReview transaction history

อ่านประวัติแบบเพิ่มอย่างเดียว และใช้รหัสรายการเป็นหลักฐานเมื่อติดต่อฝ่ายสนับสนุนRead the append-only history and use a transaction id as evidence when contacting support.

สิ่งที่ต้องมีก่อนเริ่มBefore you start

  • เลือกคลังสินค้าที่ต้องการตรวจสอบแล้วThe warehouse to inspect is selected
  • มีธุรกรรมเกิดขึ้นแล้วอย่างน้อยหนึ่งรายการAt least one transaction has been posted

ขั้นตอนSteps

  1. ในกรอบ 1 ตรวจสอบรหัสรายการ ประเภท เวลาที่เกิด วันที่ทางธุรกิจ และจำนวนบรรทัดIn box 1, check the transaction id, type, occurrence time, business date, and line count.
  2. รายการที่มีป้าย “รายการกลับรายการ” คือรายการแก้ไขที่อ้างอิงธุรกรรมเดิมA row tagged “Reversal” is a correction that references the original transaction.
  3. ใช้รหัสรายการเมื่อติดต่อฝ่ายสนับสนุนหรือตรวจสอบหลักฐานQuote the transaction id when contacting support or auditing evidence.

ตรวจว่างานสำเร็จอย่างไรHow to tell it worked

  • พบธุรกรรมที่ต้องการพร้อมรหัสรายการที่อ้างอิงได้The transaction under review is found, with a quotable transaction id.
  • ประวัติเป็นแบบเพิ่มอย่างเดียว จึงไม่มีปุ่มลบหรือแก้ไขHistory is append-only, so there is no delete or edit control.
