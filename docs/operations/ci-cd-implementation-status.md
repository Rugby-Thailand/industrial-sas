Status values:

- **Implemented**: code or configuration is in the branch, with the local
  evidence cited.
- **Kept**: an existing control is preserved.
- **Conditional / N/A**: deliberately deferred, or inapplicable, per the audit.
- **Pending live proof**: the repository part exists, but platform or workflow
  execution has not been observed.
- **Pending**: required work or evidence that this snapshot has not verified.

"Root audited" cites root/Codex results that this author did not re-run.
Platform facts are in [platform evidence](ci-cd-platform-evidence.md).
