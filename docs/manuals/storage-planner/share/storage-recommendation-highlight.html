แนะนำ Location พร้อมตำแหน่งวางจริง

เปิดหน่วยที่วัดขนาดแล้ว → แนะนำพื้นที่ → เลือกและปรับจุดวาง → ตรวจสอบ → จอง

1.1

ของชิ้นนี้ควรเก็บตรงไหน?

① เลือก Location จากรายการด้านซ้าย ② อ่านอาคาร ชั้น และพิกัดจุดวางด้านขวา ③ ดูเหตุผลว่าตำแหน่งนี้วางได้อย่างไร

ผลที่ควรเห็น ตัวอย่าง: พาเลท 0.8 × 0.8 × 0.5 ม. → MANUAL-BLDG → ชั้น 1 → โซน FG คู่มือ → X 0.5 / Y 0.5 / Z 0 ม.

ข้อควรรู้ ถ้าเงื่อนไขจัดเก็บยังไม่ระบุ ระบบจะแจ้งให้ตรวจความเหมาะสมเอง ตำแหน่งที่วางพอดีไม่ได้แปลว่าผ่านเงื่อนไขสินค้าทุกอย่างแล้ว
1.2

เริ่มจากหน่วยที่วัดขนาดแล้ว

เปิดหน่วยจัดเก็บ ตรวจขนาดภายนอกจริง แล้วกดแนะนำพื้นที่ ถ้าขนาดผิด ใช้ปุ่มวัดขนาดพาเลทเพื่อแก้ก่อนขอคำแนะนำ

ผลที่ควรเห็น ระบบใช้ขนาดของหน่วยนี้ช่วยหาตำแหน่งที่วางได้

1.3

ปรับจุดวางให้ตรงกับหน้างาน

ลากของในภาพ หรือกรอก X/Y เพื่อเลือกจุดย่อยภายใน Location ใช้ 2D ดูพื้นที่จากด้านบน และ 3D ดูระดับสูง หมุนพาเลท 90° เมื่อต้องการเปลี่ยนทิศทาง

ผลที่ควรเห็น เห็นตำแหน่งจริงที่จะวางก่อนจอง กดคืนค่าที่แนะนำเพื่อกลับไปใช้พิกัดที่ระบบเสนอ

ข้อควรรู้ X/Y อ้างอิงจุดเริ่มต้นภายใน Location; Z คือระดับฐาน หน่วยเป็นเมตร ปุ่มหมุนมุมมองเปลี่ยนเฉพาะกล้อง
1.4

ถ้าวางไม่ได้ ให้ดูเหตุผลแล้วแก้จุดนั้น

ตัวอย่างนี้ X = 4 ทำให้พาเลทล้ำขอบพื้นที่ จึงมีขอบและข้อความเตือนสีแดง พร้อมปิดปุ่มยืนยัน แก้ X/Y ลากกลับเข้าเขต หมุนพาเลท หรือเลือก Location อื่น

ผลที่ควรเห็น ดำเนินการต่อเมื่อข้อผิดพลาดของตำแหน่งถูกแก้แล้ว

1.5

พอใจตำแหน่งแล้ว ค่อยจอง

กดยืนยันจุดจัดเก็บเพื่อเปิดหน้าต่างนี้ ตรวจอาคาร ชั้น Location และพิกัดอีกครั้ง แล้วกดจองจุดนี้ หากไม่ตรงให้กลับไปแก้ไข

ผลที่ควรเห็น หลังจอง ให้นำของไปวางตามพิกัด ตรวจ QR ปลายทาง แล้วจึงยืนยันว่าจัดเก็บแล้ว

ข้อควรรู้ การดูคำแนะนำยังไม่จองพื้นที่ และการจองยังไม่ใช่การยืนยันว่าของวางจริงแล้ว
