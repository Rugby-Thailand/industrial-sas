## Independent review and fixes

The Standards review found pending lifecycle writes that could escape shell navigation protection, and successful confirmations that closed before their pending guards settled. Activation, floor removal, building/zone/position archival, scanned-record deletion, packing, and repacking now complete through their live operation and foreground owners. Regression tests exercise completion followed by the next native Back.

The Spec review reproduced accepted writes whose responses were lost. Reactive query updates could block receipt recovery or, for floor addition/removal, advance a retry into a different command. Product edits, floor counts, reviewed floor removal, named-location completion, activation, ticket correction, and ticket remapping retain the original attempted arguments and request identity. Ordinary new submissions retain current validation; server permissions, versions, and occupancy rules are unchanged.

The parent review also removed the uncancelled global layout-close queue. Layout completion now checks the current editor generation and uses its actual owner. A named-location snapshot includes the local floor choice as well as measurements, so a later choice cannot be silently discarded by an earlier save. Remounted and nested retired foreground entries are consumed before paint; retirement is coalesced, and StrictMode re-registration preserves live owners.

CI failures also exposed an incomplete barcode-preview router fixture, outdated package-scan route expectations, missing static observability path classification, English singular/plural errors, and a painted repacking receipt whose parent still considered it dirty. These were corrected without weakening the checks.

## Verification boundaries

Real caller tests use the navigation provider, history tracker, shared dialogs, and actual feature components, substituting API or hardware resources where required. Native browser navigation was exercised on desktop/mobile Chromium, Firefox, and WebKit. The PR's final required checks record combined-suite results.

The bounded visual pass inspected building, new-building, floor, settings, and package-entry surfaces at desktop and mobile widths down to 320 CSS pixels. The inspected states had readable controls, labels, and no page-level horizontal overflow. Settings conflict recovery was inspected in Thai. These captures used an isolated component harness with fake data and writes. The review screen additionally received source review; the native preview host disconnected before its final capture. This is not a physical-camera or production-data test.

Rollout compatibility, including old unversioned edit requests failing closed, is documented in [backend compatibility](../../operations/backend-compatibility.md). Lifecycle capacity limits and refusal behavior are documented in the backend review. No production data was edited during this work.
