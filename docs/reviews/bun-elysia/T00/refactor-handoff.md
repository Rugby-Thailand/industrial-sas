- The Phase 1/Phase 2 ordering, new-released-reference rule and Elysia-only supersession appear in the delivery plan's "Phase order" section and in three places in the performance plan (status callout, "Superseded" note, ledger). Each plan has to stand on its own, and these sentences carry the accepted "supersede only the Elysia deferral" boundary, so they stay.
- The Phase 2 execution workflow overlaps test-matrix steps 3, 4 and 7 (independent separate-worktree comparison, gate commands, exact-integrated-SHA gate). Codex added this text in the specification fix to apply the required cycle and current-command guarantees to Phase 2. Merging or trimming it would risk weakening an accepted guard, so it is kept and only cross-referenced.
- The phrase "wait for protected checks and required review" is kept. The ruleset requires 0 approvals, so the clause adds no approval wait. It matches the original plan text and does not conflict with protection.
- Step 4's wrapping, which runs past 80 columns, is not reflowed. Prettier preserves prose wrapping, and a reflow would add churn without changing the meaning.
- `codex-audit.md`, `external-prerequisites.md`, the JSON manifests and the prompts are other actors' records or raw evidence. They are unchanged.
