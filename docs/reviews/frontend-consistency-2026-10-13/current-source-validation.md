## หลักฐานที่เปลี่ยนการตัดสินใจ

### A01 — ข้อเท็จจริงกับส่วนที่ยังต้องพิสูจน์

- [PhotoCapture.tsx:87](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L87) กำหนด canvas เท่ากับ native video และ `drawImage(video, 0, 0)`; [PhotoCapture.tsx:132](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L132) ใช้ preview 3:4 บน mobile และ 4:3 บน desktop พร้อม `object-cover` จึงมี framing mismatch ได้เมื่อ native ratio ต่างกัน
- หลัก browser ยืนยันว่าการจัดแสดง `cover` รักษาสัดส่วนพร้อมเติมเต็มและ clip content แต่ canvas จาก video ใช้ native media frame: [W3C CSS Images §4.5](https://www.w3.org/TR/css-images-3/#the-object-fit), [WHATWG Canvas image sources](https://html.spec.whatwg.org/multipage/canvas.html#canvasimagesource) การสรุปว่าผู้ใช้จะส่งใบอื่นติดไปด้วยเป็น **inference** จากเงื่อนไขนี้ ยังไม่ได้ทดสอบ device/AI จริง
- [PhotoCapture.tsx:72](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L72) กลืน `play()` rejection แล้วตั้ง ON ทันที ทั้งที่ [WHATWG media playback](https://html.spec.whatwg.org/multipage/media.html#dom-media-play) ระบุ rejected promise ได้; [PhotoCapture.tsx:136](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L136) แสดง error/startup แบบข้อความโดยไม่มี Retry
- ไม่ควรอ้างว่ากล้องทั้งหมดไม่มี cleanup: [PhotoCapture.tsx:66](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L66) หยุด late-granted stream และ [PhotoCapture.tsx:76](../../../src/features/finishedGoods/jobScan/PhotoCapture.tsx#L76) หยุด stream ตอน unmount แล้ว
- Location camera มี native aspect/`object-contain`, awaited play, generation cancellation และ Retry อยู่แล้วที่ [LocationPhotoCamera.tsx:48](../../../src/features/finishedGoods/jobScan/LocationPhotoCamera.tsx#L48) และ [LocationPhotoCamera.tsx:135](../../../src/features/finishedGoods/jobScan/LocationPhotoCamera.tsx#L135) สิ่งที่ควรแก้เพิ่มเติมคือ [LocationPhotoCamera.tsx:152](../../../src/features/finishedGoods/jobScan/LocationPhotoCamera.tsx#L152) ใช้ permission-denied copy กับ capture/playback error ด้วย; [LocationPhotoCamera.test.tsx:89](../../../src/features/finishedGoods/jobScan/LocationPhotoCamera.test.tsx#L89) แสดงว่า failed capture ยังเข้ากรณี error/retry
