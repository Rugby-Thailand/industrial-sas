## Controls and actions

The JSON inventory records 187 exact state/overlay owners and 24 navigation action intents. Each entry specifies the expected predecessor or why the state is presentation, the owning integration, source identity, and literal regression case. Important dispositions:

| Family                                                | Final behavior / disposition                                                                                                                                                                                                                                                         | Real caller evidence                                                                                                    |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Job scan / records / Location acquisition             | Question→tickets, inline records picker, QR→AI, retake and add-location own native predecessors; chosen values and tickets survive local Back. Success/invalidated selection consumes owned entries.                                                                                 | JobScanScreen, JobScanRecords, LocationPicker, LocationPicker.ai                                                        |
| Page Headers / module hubs / denial                   | Actual origin wins after foreground handling; direct children use validated module parents. Hubs without a predecessor disable Back; auth/denial recovery omits it. Static declarations do not prove every dynamic route/data combination. Hardware camera resources are mocked in caller acquisition tests. The contract documents unchanged dynamic callers that rely on tested parent resolver evidence rather than a dedicated browser case.
