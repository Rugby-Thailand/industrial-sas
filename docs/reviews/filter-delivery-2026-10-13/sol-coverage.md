## Reconcile the base before implementing

- The research snapshot predates substantial HR and AI usage work. The latest base has `/ai-usage` and leave, announcement, notification, payslip and employee frozen-period routes. The research inventory's claim that AI usage has no source route is obsolete.
- The latest `LocationPicker.tsx:52,79,97` has `browseWithoutSearch = false`, computes `searching` from that flag or settled text, and skips blank queries. The research snapshot's local blank-browse improvement is absent from this base. Fix this actual source, not only deployment alignment.
- The positive typed exact response still does not supply `zones` (`LocationPicker.tsx:113–127`). The exact miss can still enable registration while the catalogue is incomplete. Both original defects remain.
- `convex/hr/self.ts:315` now accepts date and text criteria and walks indexed request pages. `RequestsScreen` exposes these filters. Preserve this newer behavior; do not replace it with the older research implementation.
- Shared navigation/history and stale-operation guards were improved in `#83/#84`. Preserve the latest hooks and draft guards when adding pagination. Restoring a cursor does not by itself restore a component-local search/filter.
- The latest base still has the important collection gaps below. Existing `.all(limit)` reads detect overflow; they are not silent truncation. An explicit capacity refusal is safer than omission, but it is still not continuation.

## Explicit exceptions and boundaries

- Personal time history is a complete selected ≤31-day range; annual holidays are a complete year. Keep month/year navigation, improve holiday retrieval from 365/366 point reads to a date-range query, and do not add arbitrary row paging to the calendar.
- A day form is not a collection. Its correction history is a growing child list: `dayDetail.ts` shows newest20 and flags incompleteness, so offer older corrections or an explicit filtered link into the existing paged requests list. Prior certifications are write-bounded to50 (`review.ts:242,244`); correction resubmission history is bounded to200 (`self.ts:59,856`). Clock facts/controls remain together.
- Batch packing/repacking input is limited to50 packages (`model/finishedGoods/packing.ts:3`), enforced by packing validation and replacement count. A complete editing draft is required for totals and atomic replacement; its history relations can still grow and should use status-specific/current-state reads.
- Structural layout limits are write/domain bounds (`storageLayout.ts`:50 floors/100 reserved blocks; `storageZone.ts`:500 zones/floor/50 placements/zone; `storagePosition.ts`:100 positions/area). Complete draft/geometry context is intentional. These bounds do not justify fetching every building before showing one table page.
- Floor maps, placement previews, support stacks and selected-zone occupancy are authoritative spatial views. Paginate companion record lists; don't omit off-page geometry from collisions/recommendations/save validation.
- Navigation, shortcuts, fixed leave-type/account cards, policy fields/sources, setup checklist, language/theme choices, profile facts, comparison fields and finite scanner acquisition controls are not growing collection lists.
- Global navigation search is a suggestion surface (top8 plus explicit incompleteness), not an exhaustive record list. Keep truthful suggestions and link to complete paged results.

## Concrete implementation blockers / review priorities

1. **P0:** Remove actual base blank query gate, render typed exact choices, suppress ordinary typed registration/empty states until complete, and add scoped icon filter/options. Exact choices outside selected building must not bypass it.
2. **P0:** A source-level prefix/index query is incomplete without all writers, physical/support relationships, rename/archive/delete invalidation, tenant-safe range adapter and bounded backfill/readiness. No new path should activate on partially populated projection data.
3. **P1:** Do not stop at the old research inventory: include manager leave queue, silent pallet move-history20, grouped AI breakdown/options, day correction history and older period-version discovery.
4. **P1:** Replace whole-history scans for saved scans/custom catalogue sorts and one-zone physical-location continuations. A footer alone cannot pass latency/read-count acceptance.
5. **P1:** Paginate HR employees/review groups/periods/settings/members/audit at the source. Reachability beyond99/200 must be tested, including eligible late matches and derived attendance blockers.
6. **P1:** Preserve complete exports, close-period fingerprints, selection scope, drafts, recommended destination, collisions/support relationships and off-page direct-ID lookup. Preserve new navigation/identity behavior.
7. **P2:** Make shared page sizes configurable. HR requests max50, announcements/notifications max30, frozen periods25, and some lists fixed20; an unmodified 20/50/100 selector is not compatible with all endpoints.
