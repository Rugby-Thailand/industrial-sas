## Recommended fix order

1. Preserve HR drafts across subscription updates while retaining the loaded revision. Require explicit reconciliation before submitting against a new revision; simply substituting the live revision would bypass stale-record protection.
2. Retain exact effective certification timestamps for untouched re-review fields. The backend needs an explicit revision-checked retention contract; simply changing the UI's boolean flag is insufficient when original and certified times differ.
3. Refresh clean stacking forms from live data, retain dirty drafts, and reject stale writes using a settings baseline/revision.
4. Complete the known error/recommendation mappings in both languages and show one accurate conflict notice. Keep unknown failures safely generic.
5. Consolidate location/profile identity and empty-state copy. Preserve useful distinct names, accessibility descriptions and Back/Close semantics.

Any navigation or foreground changes made during fixes must follow the existing Back contract and caller regression requirements. This audit did not change navigation.

## Additional observations, not counted as confirmed bugs

Kiro's independent report intentionally has a broader UI list. The parent triage keeps these observations separate:

- **Today links to itself in the configurable shortcut list (K-HR-02).** The self-link exists, but no requirement establishes that it is forbidden. Treat hiding the current destination as a UX choice rather than a functional defect.
- **“1 unit” appears in a metric and inventory summary (K-STO-02).** These are two distinct contexts. Consolidation may reduce repetition, but the data is consistent and the repeated word alone does not prove a bug.
- **The desktop inspector has two X controls (K-STO-03).** One hides details while retaining selection; the other clears selection. They have distinct accessible names and behavior. Consider clearer visual affordances, not deletion of one as a supposedly duplicate action.
- **Bilingual/locale copy (K-STO-04, K-LOC-01/K-LOC-02).** The real Thai floor stamp contains `ชั้น / FLOOR 02`, Thai Quick Change labels include English, and English AI Search examples/date hints contain Thai. The strings were verified. Whether all bilingual copy should be removed needs the intended language/technical-label convention; these are localization cleanup candidates, not runtime failures. Existing tests explicitly exercise some Thai search examples even with English UI.
- The detector's three warnings were confined to `_prototype` files and were excluded. The possible overlapping-rack case was excluded by Sol because the intended domain rule and a material faulty outcome were not established.

This was a bounded bug search, not proof that every workflow is correct.

Component probes control subscription responses; in-memory handlers do not reproduce production network timing. The screenshots use the fallback inspector, while Kiro's tests cover the main building workspace.
