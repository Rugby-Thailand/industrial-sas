Click-by-click flow
  1. Add finished good → Opens the full product-details page. This is step 1 of 2.
  2. Next: Measure → Opens step 2 for the physical pallet, actual quantity, and external dimensions.
  3. Save and find storage → Shows a precise proposed position inside a location, with fit checks.
  4. Adjust position → Opens an inline panel for dragging, X/Y coordinates, and 90° pallet rotation.
  5. Confirm spot → Opens a destination-review dialog. Nothing is reserved until Reserve spot is clicked.
  6. Reserve spot → Holds the space and shows movement instructions. The pallet is still awaiting storage.
  7. Scan destination QR → Opens a scanner dialog. A matching code enables physical storage confirmation.
  8. Confirm stored → Records the operator-confirmed exact placement and shows the occupied position.
