Use case: ui-mockup.
Create a polished high-fidelity UI design presentation for an existing Thai warehouse storage planner. Landscape board, 1800x1200 or similar. Two clearly separated flat app mockups: a large DESKTOP design at left occupying 70%, and a MOBILE design at right occupying 25%. Small heading outside frames "ยืนยันย้าย — แบบใหม่". This is a proposed design, not a screenshot of the live app.
Visual style: minimal precise dark enterprise app, near-black #0b1216 background, charcoal #1c252f panels, fine gray borders, soft blue primary button, mint success accents, clean readable Thai sans-serif. No shiny gradients, no decorative fake charts. Small outlined icons and slim icon-only sidebar. Compact top bar warehouse QA-MAIN, Thai locale.
Main desktop screen in IN TRANSIT state:
Back link at top left "กลับไปที่พาเลท". Title "ยืนยันย้ายพาเลท". Compact horizontal three-step indicator "เลือกปลายทาง" checked, "กำลังย้าย" active, "เสร็จสิ้น" pending.
One compact product summary line "P-000001 · FG-001 · 500 ชิ้น".
Immediately below: two-column main body. LEFT 58%: compact 2D/3D toggle, realistic simple isometric wireframe storage spot 4m x 4m with a tan pallet at highlighted destination; a few muted existing pallets for context, legible target pin label "POS-000028", thin geometry strokes. Don't let map consume whole height.
RIGHT 42%: primary confirmation card visible without any scroll. Heading "วางที่ปลายทางนี้". Prominent "สินค้าสำเร็จรูป A", breadcrumb "DEMO-BLDG → ชั้น 1", target "POS-000028", concise coordinates "X 1 m · Y 0 m · Z 0 m". Thin divider. A LARGE CHECKED CHECKBOX with label "ฉันวาง P-000001 ที่ปลายทางนี้แล้ว". Directly below a big full-width blue button with check icon "ยืนยันย้ายเสร็จ". Above main columns a very compact single line source → destination strip "POS-000001 → POS-000028".
Mobile: same state and information, compact header, pallet code, destination card FIRST, short breadcrumb and target coordinates. A compact isometric map preview beneath destination info. Use exact Thai text as specified, readable at normal viewing size. Keep all important content inside both frames.
