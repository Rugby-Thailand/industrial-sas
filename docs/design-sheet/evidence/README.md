# Evidence scope

`adoption-checks.json` is regenerated by the root-sheet DOM contract check (`check-adoption.cjs`). It covers 68 language/theme/state combinations and evaluates only the vanilla `sheet.js`/`review.js` handlers: selects, dates and times appear as their hidden native sources, not as the mounted React controls. `adoptionRevisionDate` and `adoptionGitBase` name the 2026-10-11 revision; `checkedAt` and `gitHead` describe the run.

`check-controls.cjs` loads the built islands (`dist/controls.js`) with the sheet scripts and writes `controls-checks.json`. It covers selection, draft retention, confirm-safe and explicit date clearing, the time draft (Done/Escape/outside click/empty/incomplete/clear), Thai Buddhist-year visible and accessible names, state specimens, pressed/disabled/pending/read-only token cascades, print-from-dark behavior and stylesheet coverage, script-failure fallback, accessible names, structural axe with popups open, and build output. Assertions are grouped by audit ID. Build with `pnpm build:design-sheet` first. Cascade checks map each `var()` to a sentinel color, so they show which token wins, not rendered pixels; popup geometry and print rendering need a browser.

[audit-fixes-2026-10-15.md](audit-fixes-2026-10-15.md) maps DS-A01–DS-A21 to their resolution and evidence.

`field-ui-checks-2026-10-14.json` records the earlier compact-field pass before the shadcn replacement. Its screenshots and numeric alignment results belong to that earlier version. `shadcn-ui-checks-2026-10-14.json` records the later controls work and its separate limits.

All pre-existing screenshots, `browser-checks.json`, `copy-checks.json` and `review.md` describe the original proposal at `8b0ef538` (including its earlier focus/copy refinements). They have not been regenerated for the adoption revision. They are a visual baseline and history, not proof of the new states, density or domain corrections.

Variant assets are frozen separately under `../variants/`. The later T3 session could inspect the live DOM and open the real controls, but screenshot capture failed. Fresh visual approval, full browser axe and physical-device review remain open.

`audit-fixes-browser-2026-10-15.json` records the parent T3 pass: 56 settled state combinations, 32px/40px geometry and centered icons, native keyboard confirmations, short-screen scrolling, and final script-failure handling. `audit-fixes-2026-10-15.md` maps all 21 findings and the additional keyboard fix to evidence. Current final totals: 159 control assertions and 4,684 vanilla specimen assertions; these count different surfaces and are not a blanket accessibility certification.
